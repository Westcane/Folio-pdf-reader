# Folio PDF阅读器

Folio 是一款面向 iPad、也可以在桌面浏览器使用的轻量级 PDF 阅读器，采用 PWA（渐进式 Web 应用）形式。

**Folio 是为满足个人阅读需求而开发的自用工具，希望能为有类似需求的人提供帮助。**

## 可以做什么？

- **本地导入 PDF。** 选择设备上的文字型 PDF，无需注册账号，原始文件不上传到服务器。
- **自由重排文字。** 支持常见单栏、双栏排版，尽量还原段落与标题，自动处理部分跨行断词和跨页续段。
- **舒适阅读。** 采用上下连续滚动，支持字号、行距、页边距调整，以及浅色、护眼、深色主题；文字可以选取和复制。
- **接着上次的位置读。** 书籍、阅读进度和显示设置保存在设备本地；调整字体或旋转屏幕后，尽量保持原来的阅读位置。
- **随时核对原文。** 从重排段落跳转到原 PDF 页面，查看公式、图表或可疑的段落顺序。
- **可选英中对照翻译。** 接入 DeepSeek 后，支持逐段翻译、翻译可见内容、确认后批量翻译，以及收起译文和缓存已翻译段落。
- **支持离线阅读。** 在支持的 HTTPS PWA 环境下，已缓存的应用资源和本地保存的文档可用于离线阅读。

目前支持导入的单个 PDF 上限为 **50 MB、300 页、200 万提取字符**。

## 快速开始

需要 [Node.js](https://nodejs.org/) **22.13 或更新版本**，以及 npm。

克隆项目后，在项目目录中运行：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址（通常为 `http://localhost:5173/`），即可导入 PDF，或点击首页的「试读示例」。

在 **Windows PowerShell** 中，如果直接运行 `npm` 遇到脚本执行策略限制，把命令改为 `npm.cmd` 即可：

```powershell
npm.cmd ci
npm.cmd run dev
```

### 在 iPad 上测试

让 iPad 和开发电脑连接同一个可互访的局域网。启动开发服务后，使用终端显示的 **Network** 地址在 iPad Safari 中打开，例如 `http://192.168.x.x:5173/`。

这里的 IP 只是示例；请以自己电脑的实际局域网地址为准。局域网 HTTP 适合测试阅读界面，但不能完整验证 PWA 安装与离线能力。

## 可选：启用 DeepSeek 双语翻译

本地使用翻译功能时：

1. 将 `.env.example` 复制为 `.env.local`。
2. 在 `.env.local` 中填写 `DEEPSEEK_API_KEY=你的密钥`。
3. 单独运行 `npm run api`，启动本机 Node 翻译代理。
4. 保持前端开发服务运行，在阅读器中打开双语设置并按需翻译。

Windows PowerShell 可使用 `npm.cmd run api`。

**隐私与费用说明：** PDF 导入和文字重排在本地完成。使用翻译时，所请求的原文会发送给 DeepSeek 服务；确认全文翻译后会提交相应段落，可能产生 API 费用。密钥由本地 Node 服务读取，**请不要泄露API和 `.env.local`**。翻译结果缓存在本地。

## 使用限制

Folio **不是万能的 PDF 转换器**。目前尤其需要留意以下情况：

- **扫描件和图片版 PDF**：暂不提供 OCR 文字识别。
- **复杂版式**：表格、公式、图片、脚注、跨栏结构和参考文献可能无法准确重排，建议查看原始页面。
- **文字读取顺序**：段落重建使用启发式规则，不能保证所有双栏论文、跨页段落都被正确识别。
- **受保护或特殊字体 PDF**：密码保护文档、异常字体编码、旋转或竖排文字等暂不能保证支持。
- **阅读功能**：目前以连续滚动阅读为主；全文搜索、书签、OCR、译文导出等功能尚未提供。

如果阅读内容出现错序或缺失，请以原始 PDF 页面为准。
