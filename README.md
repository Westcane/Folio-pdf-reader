# Folio PDF 阅读器

Folio 是一款面向 iPad、安卓手机和平板，也可以在电脑浏览器使用的轻量级 PDF 阅读器。

**Folio 是为满足个人阅读需求而开发的自用工具，希望能为有类似需求的人提供帮助。**

## 可以做什么？

- **本地导入 PDF。** 选择设备上的文字型 PDF，无需注册账号，原文件不上传。
- **自由重排文字。** 尽量还原段落与标题，处理常见单双栏排版、跨行断词和跨页续段。
- **按自己的习惯阅读。** 可选左右翻页或上下滚动，调整字号、行距、页边距，以及浅色、护眼、深色主题。
- **接着上次的位置读。** 书库、阅读进度和设置保存在设备本地，关闭后重开可以继续阅读。
- **英中对照翻译。** 使用自己的 DeepSeek API Key，支持逐段、一页和确认后的全文翻译；译文可收起，也会保存在本机。
- **安装与离线阅读。** 可添加到主屏幕，离线阅读已保存的文档和译文；新翻译需要联网。

## 怎么使用？

1. 打开 Folio，选择 PDF 文件，或点击「试读示例」。
2. 打开书籍，在「阅读设置」里选择翻页方式、字号和主题。
3. 单击原文段落，可以翻译、展开或收起译文；悬浮翻译按钮用于翻译当前一页。
4. 双击正文可以唤出或收起工具栏，停留一会儿也会自动收起。
5. 点击顶部书名或页码，可以拖动进度条快速跳页。

iPad 在 Safari 的「共享」中选择「添加到主屏幕」；安卓在 Chrome 菜单中选择「安装应用」或「添加到主屏幕」。首次使用时请联网，等待应用缓存完成。

## 可选：启用 DeepSeek 翻译

在书库打开「API 设置」，或在阅读器中选择「翻译 → API 设置」，填入自己的 DeepSeek API Key，选择模型后保存即可。默认官方地址可以直接使用，无需另开翻译服务器。

Key 会保存在当前浏览器，重新打开不需要反复填写；可以随时清除，书籍和已有译文仍会保留。请不要在共享设备保存密钥，也不要把密钥发给别人。

**隐私与费用说明：** 阅读和 PDF 重排在设备上完成。翻译时，选中的原文段落会直接发送给 DeepSeek，使用你自己的 API 额度。全文翻译需要确认；已有译文再次展开不会重复请求。工具本身免费，DeepSeek API 费用由服务商收取。

## 在电脑上运行

安装 Node.js 22.13 或更新版本，用 VS Code 打开项目，在 PowerShell 终端运行：

```powershell
npm.cmd ci
npm.cmd run dev
```

在 Chrome 或 Edge 打开终端显示的 Local 地址，通常是 `http://localhost:5173/`。若服务已经启动，直接使用已有地址即可。停止时在终端按 `Ctrl+C`。

在 iPad 或手机上测试时，让设备与电脑连接同一个局域网，打开终端显示的 Network 地址。正式网站安装到主屏幕后，日常使用不需要电脑保持开机。

## 使用限制

- 单个 PDF 最大 **50 MB、300 页**，暂不支持扫描件 OCR。
- 表格、公式、图片、复杂论文和特殊字体可能无法准确重排，请保留原 PDF，必要时用原阅读器核对。
- 清理网站数据、浏览器回收存储或更换设备可能移除书库、进度、Key 和译文。安装到主屏幕不等于备份。
- 全文搜索、书签和译文导出尚未提供。
